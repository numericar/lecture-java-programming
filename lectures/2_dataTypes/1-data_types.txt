
    :: Data Types
    เป็นการระบุชนิดของข้อมูลที่เรากำลังจัดเก็บ โดยใน java จะมีชนิดข้อมูลอยู่ 2 รูปแบบ

    :: Primitive Data Type (ชิดข้อมูลดั้งเดิม)
    เป็นชนิดข้อมูลที่มีอยู่แล้วใน Java
    > Integer
    จัดเก็บตัวเลขจำนวนเต็ม
        - byte
            - size: 1
        - short
            - size: 2
        - int
            - size: 4
        - long
            - size: 8
    > Floating Point
    จัดเก็บเลขที่มีทศนิยม
        - float
            - size: 4
        - double
            - size: 8
    > Character
    จัดเก็บตัวอักษร
        - char 
            - size: 2
    > Boolean
    เก็บค่าจริงเท็จ
        - boolean
            - size: ?
            - สาเหตุที่ size ไม่แน่นอนเพราะ ขึ้นอยู่กับ Environment หรือ JVM โดยอาจจะใช้ตั้งแต่ 1 bit ~ 4 byte
